# Python Data Science Foundations

A hands-on collection of Jupyter notebooks for building practical Python data science skills with NumPy, Pandas, Matplotlib, and Seaborn.

## Repository Overview

This repository brings together four focused notebooks covering the core tools used in data analysis, visualization, and early machine learning workflows.

| Notebook | Focus |
|---|---|
| `NumPy.ipynb` | Arrays, vectorized operations, statistics, linear algebra, preprocessing, and ML/DL fundamentals |
| `Pandas.ipynb` | DataFrames, cleaning, filtering, grouping, merging, reshaping, time-series operations, and ML preparation |
| `Matplotlib.ipynb` | Core plotting, subplots, distributions, model evaluation plots, and visualization fundamentals |
| `Seaborn.ipynb` | Statistical visualization, EDA, categorical plots, heatmaps, regression plots, and ML-focused visual analysis |

## What You Will Practice

- Creating and manipulating NumPy arrays
- Cleaning and transforming tabular data with Pandas
- Filtering, grouping, merging, pivoting, and reshaping data
- Handling missing values, duplicates, dates, and categorical variables
- Building line, bar, scatter, histogram, box, and heatmap visualizations
- Exploring relationships and distributions with Seaborn
- Preparing data for machine learning workflows
- Visualizing predictions, residuals, confusion matrices, feature importance, and training curves
- Applying basic statistics and linear algebra concepts used in data science

## Setup

Clone the repository:

```bash
git clone https://github.com/MuhammadTalha1404/python-data-science-foundations.git
cd python-data-science-foundations
```

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the main dependencies:

```bash
python -m pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

Then open the notebooks in Jupyter or VS Code and run the cells from top to bottom.
