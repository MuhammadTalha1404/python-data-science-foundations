WDBC Analysis Project

Open WDBC_Classification_Analysis.ipynb in VS Code or Jupyter and run the cells from top to bottom.

Included files:
- wdbc.data.txt: original raw dataset
- wdbc.names.txt: dataset documentation
- wdbc_prepared.csv: cleaned dataset with headers
- WDBC_Classification_Analysis.ipynb: prepared and executed analysis notebook

If VS Code asks for a kernel, select a Python environment containing pandas, numpy, matplotlib, seaborn, and scikit-learn.
